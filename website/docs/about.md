# About this project

ModernOps Showcase is a public reference project for modern infrastructure and
agentic engineering. It exists to show how infrastructure is planned, built,
tested, operated and reviewed -- with reproducible scenarios instead of slides.

## Principles

- **Reproducible over impressive:** every lab can be run from a clean clone.
- **Honest status:** `planned`, `experimental`, `implemented`, `validated`.
- **No fabricated results:** evidence comes from real runs.
- **Free and open:** MIT licensed, no paid services, no cloud account required.
- **Security by default:** least privilege, no secrets, human approval before
  merge.

## Scope and limits

This is a showcase, not production software. There is no SLA, no support
contract and no production deployment. Some parts are deliberately not built --
see the [technology stack](technology.md) and the twelve ADRs.
